盾构隧道

在软土、砂层或河底开挖隧道，最大的危险是开挖面和洞壁坍塌、地下水涌入。盾构法用一个与隧道断面相同的钢制圆筒（盾壳）作为临时支护：盾构机前端的刀盘旋转切削土体，切下的土由螺旋输送机等排出；盾壳顶住四周的土压和水压，工人和设备在盾壳保护下作业；千斤顶顶着已拼装好的管片把盾构机向前推进，每推进一环的距离，就在盾尾拼装一圈预制钢筋混凝土管片，形成永久衬砌。土压平衡盾构还通过控制刀盘后方土仓的压力，使其与前方土压平衡，防止地面沉降。隧道断面多为圆形，因为四周的土压和水压从各个方向作用，圆环能把荷载转化为沿环向的压力，混凝土抗压性能好，受力最均匀。1825 年布鲁内尔开始用盾构法开挖伦敦泰晤士河隧道（拍摄前核对），据说灵感来自船蛆在木头中钻孔。

暂定标题在软软的泥沙里挖隧道，为什么不塌？

背景

起源

1825 年布鲁内尔开始用盾构开挖泰晤士河隧道，1843 年通行（拍摄前核对）。

今天

城市地铁、过江过海隧道普遍采用盾构法。

原理

盾壳临时支护；管片衬砌；圆环受压；土压平衡。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1挖得够快就不塌 → 盾壳顶住土，边挖边装管片
  2. 2刀盘越大越好 → 刀盘、推力和泥土压力要配好
  3. 3隧道做成圆的是为了好看 → 圆环受力最均匀

三层「为什么」

现象层

湿沙里推进纸筒：不套筒挖洞会塌，套着筒边挖边推不塌

规律层

盾壳顶住土压；管片拼成环

本质层

刀盘、土压平衡与管片

原理 → 设计决策：要在河底软土里开一条路 → 用一个钢筒顶住四周的土 → 筒里挖、筒后装管片，一节节往前推。

实验设计

湿沙：细沙加水到用手一捏能成团、不滴水，分层装进鞋盒（或透明塑料盒）每层压实，盒子侧面开一个比纸筒略大的圆口。盾壳：一段卫生纸筒，前端边缘剪成小锯齿当「刀盘」。管片：吸管剪成 3 厘米长，竖着贴在纸片上卷成圈。方筒、圆筒用同样大小的卡纸。沙子在托盘里操作，做完洗手。

操作步骤

  1. A：各挖 3 次，量塌前深度。
  2. B：纸筒退出时塞入吸管管片，看洞是否保持。
  3. C：同周长圆筒、方筒压书，数本数。
  4. D：坐地铁拍隧道接缝。

安全提示
  • 沙子在托盘里操作，别弄进眼睛；做完洗手。
  • 压书实验书堆不要太高，防止倒下砸手。
  • 地铁拍摄时远离站台边，遵守站内规定。
