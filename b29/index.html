交子防伪

交子是世界上最早的纸币之一。一张纸要当钱用，难点是防伪：用两块版黑红套印（朱墨间错），仿造者要同时仿准两块版；加上只有发行者知道的暗记（隐密题号），每多一种暗记，猜中的机会就再乘一个小数；发行时留存根、按号登记，重号或对不上的就是假券。本集只用自己设计的示意券，不仿制任何真实货币。

暂定标题世界上最早的纸币怎么防假？
时长约 3 分 36 秒 · 13 个镜头
时代北宋 · 1023 年设益州交子务
衔接← B28 双动活塞风箱；接 B2 活字印刷；→ 第九季特辑

背景

私交子

北宋初年，成都商户联合发行交子，记载为「表里印记，隐密题号，朱墨间错，私自参验」（原文与出处拍摄前核对）。

官交子

天圣元年（1023 年）设益州交子务，次年开始发行官交子（公历换算拍摄前核对）。

今天

现代纸币用多色套印、凹版细线、水印、安全线和冠字号码，思路一脉相承。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1纸币就是印了字的纸 → 要靠难仿的印刷和暗记
  2. 2防伪是现代才有的 → 北宋交子就用了套色和暗记
  3. 3图案越复杂越安全 → 还要有看不见的暗记和存根

三层「为什么」

现象层

仿券放大能看出破绽

规律层

套色对位；独立暗记的概率相乘

本质层

信用货币：发行、存根、兑换

原理 → 设计决策：要让纸当钱 → 印版难仿 → 两色套印 → 加只有发行者知道的暗记 → 留存根按号核对。

操作步骤

  1. A：两块橡皮章，一块刻细线边框和房屋花纹（黑版），一块刻印记和三道红条（红版），四角各刻对位十字；先盖黑再盖红。
  2. B：请 3 位朋友各看 1 分钟原版，再用 5 分钟仿印一张；用放大镜检查对位十字和细线，记录认出几张。
  3. C：在原版上加一个暗记（某根细线断开一小段），不告诉朋友，再让他们仿；记录多少张漏掉暗记。
  4. D：给原版券编号，在本子上登记；混进一张重号券，翻存根查出来。
