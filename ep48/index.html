数字与 0

位值制让同一个符号在不同位置代表不同大小，0 占住空位；有了它，十个符号就能写出任何数，竖式让乘除可以一位一位地算。

暂定标题为什么换了写法，算账就变快了？
时长约 3 分 36 秒 · 13 个镜头
时代战国算筹 · 印度数字 · 1202 年斐波那契
衔接← B10 透光镜；→ 49 复式记账

背景

算筹

中国算筹至迟在战国就是十进位值制（纵式、横式交替），空位留白；后来用圆圈表示零。北宋时商人、官府都用算筹计算。

印度与 0

628 年印度数学家婆罗摩笈多在著作中给出了关于 0 的运算规则；印度数字经阿拉伯世界传播。

欧洲

1202 年斐波那契在《计算之书》中介绍印度—阿拉伯数字；此前欧洲多用罗马数字，计算依靠算板。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1数字怎么写都一样 → 写法决定能不能列竖式
  2. 20 就是「没有」 → 0 还要「占住位置」
  3. 3古代中国没有位值 → 算筹早就是十进位值制

三层「为什么」

现象层

竖式比罗马数字快得多

规律层

位值制：数值 = 符号 × 10 的位数次方

本质层

0 作为占位符和一个独立的数

原理 → 设计决策：要快速计算 → 每一位能对齐 → 位值制；空着的位要区分 → 用 0 占位；要在纸上算 → 竖式。

  4. D：请一位家人分别读出 1786 和 MDCCLXXXVI，计时。
