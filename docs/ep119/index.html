加密

加密是用一把「钥匙」把明文变成别人看不懂的密文，收信人再用钥匙变回来。凯撒密码把每个字母在字母表里后移固定位数（如 3 位，HELLO→KHOOR），钥匙就是位数；但它只有 25 种可能，逐一尝试即可破解（穷举）。钥匙越长、可能性越多，穷举越难：现代对称加密的钥匙常为 128 位或 256 位二进制数，可能性多到无法试完。剩下的难题是，从没见过面的双方如何约定钥匙。双锁箱演示了思路：甲上锁寄出，乙加锁寄回，甲取下自己的锁再寄，乙打开；全程箱子都锁着，钥匙从不离手。1976 年迪菲和赫尔曼提出公钥思想，1977 年 RSA 算法问世：每人有一把公开的「锁」（公钥）和只有自己持有的钥匙（私钥）。浏览器地址栏的小锁表示网页使用 HTTPS，正是用公钥方法先安全约定钥匙，再加密传输。

暂定标题网上付钱，为什么别人截获了也看不懂？

衔接← 91 程序与计算机、97 二维码；→ 120 核电站

背景

凯撒密码

据苏埃托尼乌斯记载，凯撒以字母后移三位通信。

公钥

1976 年迪菲与赫尔曼发表密钥交换；1977 年李维斯特、沙米尔、阿德曼提出 RSA（拍摄前核对）。

今天

HTTPS、网上支付、聊天软件端到端加密。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1加密就是把字换成看不懂的符号 → 关键是钥匙：没钥匙换不回来
  2. 2密码方法要保密才安全 → 方法可以公开，钥匙保密就行
  3. 3交钥匙必须先见面 → 公钥方法隔着网也能约定

三层「为什么」

现象层

密码轮盘：挪三格加密、挪回解密

规律层

穷举：钥匙越多越难破

本质层

双锁箱与公钥加密

原理 → 设计决策：要在全是偷看的路上传秘密 → 用钥匙打乱文字 → 再想办法不见面就约定钥匙。

实验设计

密码轮盘：两张硬纸板剪成直径 15 厘米和 11 厘米的圆，外缘各等分 26 格写 A–Z，中心用图钉或两脚钉穿起来能转。剪刀由成年人使用。双锁箱：一个有搭扣、能挂两把锁的小盒子，两把挂锁各配钥匙，甲乙各管一把，钥匙全程不交换。破解计时由第三人计。

  1. A：一人加密，另一人一格格试，计时。
  2. B：换成按 3、1、4 轮换挪格，再请人破解。
  3. C：两把锁来回寄三趟，记录每一趟箱子上挂着谁的锁。
  4. D：拍浏览器地址栏的小锁。
