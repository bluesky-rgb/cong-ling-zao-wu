印章

印章是把文字或图案刻在石、玉、铜、木、角等材料上，蘸印泥压印到纸或封泥上作为凭证的工具，先秦时已有玺印（拍摄前核对）。印章压印是一种「接触复制」：印面朝下贴到纸上，印面上的左右方向在纸上正好对调，印出来的是印面的镜像。所以要盖出正字，印面上的字必须反刻；刻章时通常先把字写在薄纸上，翻过来贴到印面上照着刻（「反稿上石」）。活字印刷的字模、拓印、木版年画的雕版都遵循同样的镜像关系。凸起的笔画（朱文）沾印泥后留下红色的字，凹下的笔画（白文）则在红底上留下白字。盖印时印泥要沾匀，压力要均匀分布到整个印面：压力不足的地方印泥转移不全，笔画断续缺损；压力过大时橡皮或软材料被压扁，印泥被挤向笔画两侧，笔画变粗，若再晃动则出现重影。纸下垫一层稍软的衬垫，可以弥补印面和桌面的不平，使各处受力更均匀。本集刻橡皮章用的刻刀只由成年人使用，孩子只画稿。

暂定标题印章上的字为什么要刻成反的？盖得太轻太重，为什么都印不清楚？
时长约 3 分 36 秒 · 13 个镜头
时代先秦已有玺印
衔接← B3 活字印刷、B77 拓印；→ 第三十季特辑

背景

出现

先秦已有玺印（拍摄前核对）。

今天

印章、橡皮章、邮戳、印刷电路板的丝网印刷。

原理

镜像对称；接触转印；压强分布。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1刻成正字盖出来也是正的 → 盖出来是镜像，所以要反着刻
  2. 2越用力越清楚 → 太轻缺笔，太重糊边
  3. 3垫得越硬越好 → 垫一层软的，受力更均匀

三层「为什么」

现象层

在纸上写字对着镜子看；刻橡皮章用不同力度盖

规律层

镜像翻转，压力要均匀

本质层

镜像对称与压强

原理 → 设计决策：要一个能反复盖出同样字样的凭证 → 把字刻在一块材料上，蘸印泥压在纸上 → 字要反刻，用力要匀。

实验设计

画稿：在白纸上用软铅笔写一个笔画简单的字（如「山」「上」）和自己的姓，用小镜子照着看，再把纸翻过来贴在窗上描出反字。刻章：一块大号橡皮（约 5 × 3 厘米），把描好的反字用铅笔拓到橡皮上（铅笔面贴橡皮用指甲刮），由成年人用刻刀沿笔画两边刻掉空白部分，留下凸起的笔画（孩子只画稿，不碰刻刀）。盖印：用印台蘸匀，分别轻按、正常按、用力按并左右晃各盖一次，再在纸下垫一本软本子盖一次。

  1. A：写字照镜子，描反字。
  2. B：成年人刻章，盖一次看正反。
  3. C：轻、正常、用力晃各盖一次。
  4. D：垫软本子再盖一次比较。
