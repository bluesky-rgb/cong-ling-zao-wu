还要对照原书的（14 条）

多是古籍原文，网上取不到可靠全文。拍到哪集，核对哪集：标「高」的会在片中念出原文，拍之前一定对一遍。勾选状态只保存在这台设备上。

核对的规矩

  • 古籍以维基文库或权威点校本为准，记下卷次。
  • 数字至少找到一个可公开查到的来源，写进拍摄本的「资料来源」。
  • 找不到出处的说法，片中改成「据记载」「一般认为」，或者干脆不说。
  • 核对完把结果发给 Claude，会改拍摄本、重渲资料卡。
