机械计算器

机械计算器的每一位是一个十个齿的轮子，转一格加一。关键是进位：个位从 9 转到 0 的那一刻，轮上的拨齿把十位推一格。连续进位（如 999 + 1）要一次推动好几个轮子，力气和可靠性是最大的难题。1642 年帕斯卡做出加法机；约 1673 年莱布尼茨的步进轮让机器能做乘法；机械计算器一直用到 20 世纪电子计算器普及。

背景

帕斯卡

1642 年 19 岁的帕斯卡为帮父亲算税做出加法机（Pascaline），进位用一个先抬起再落下的小重锤（拍摄前核对）。

莱布尼茨

约 1673 年莱布尼茨发明步进轮，机器能做乘法；更早的席卡德计算钟（1623 年）记载存疑。

普及

19 世纪的托马斯算术仪、20 世纪的手摇计算器在办公室普及，1970 年代被电子计算器取代。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1计算器必须用电 → 齿轮也能算
  2. 2进位很简单 → 进位是最难的一步
  3. 3机械计算器只能做加法 → 步进轮能做乘法

三层「为什么」

现象层

转一圈满十进一

规律层

十齿轮计数与进位拨齿

本质层

连续进位的力与可靠性

原理 → 设计决策：要算得快又不出错 → 每一位用一个十齿轮 → 满十拨动下一位 → 解决连续进位。

实验设计

打印十齿纸齿轮（网上齿轮生成器）贴硬纸板，图钉当轴；个位齿轮上多粘一根长拨齿。

组 做法 检验什么
A两位纸齿轮计数器进位
B算三道两位数加法可靠性
C三位数 99→100连续进位
D看老水表数字轮实物

操作步骤

  1. A：打印两个十齿齿轮贴在硬纸板上剪下，标 0–9；个位齿轮「9 到 0」之间粘一根加长的拨齿，转过时正好推动十位一格；图钉固定在底板上。
  2. B：算 37+48、59+26、19+81：先把个位拨到答案需要的格数，再拨十位，看进位是否每次成功。
  3. C：再加一个百位齿轮，从 99 拨到 100，感受两级进位的阻力。
  4. D：拍一个老式水表或机械里程表的数字轮。
