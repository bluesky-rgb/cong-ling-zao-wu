透镜

光从空气进入玻璃会改变方向（折射）。凸透镜中间厚、边缘薄，越靠边的光拐得越多，平行光就汇到同一点：焦点。物体放在焦距以内，眼睛看到放大的虚像，放大倍数约为 25 厘米 ÷ 焦距；焦距越短，放得越大。

暂定标题一滴水为什么能把字放大？
时长约 3 分 36 秒 · 13 个镜头
时代约 1011–1021 年伊本·海赛姆 · 约 1286 年眼镜
衔接← 21 玻璃、B10 透光镜；→ 53 显微镜

背景

同一时代

伊本·海赛姆约 1011–1021 年写成《光学之书》，系统研究了反射和折射，正与北宋同一时期。

中国

沈括《梦溪笔谈》讨论过阳燧（凹面镜）成倒像、以及小孔成像的道理；宋代也有用透明的水晶、琉璃聚光取火的说法（具体记载拍摄前核对）。

眼镜

约 1286 年意大利出现眼镜（凸透镜矫正老花），是透镜最早的日常用途之一。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1放大镜把东西变大了 → 东西没变，是光的方向变了，眼睛看到虚像
  2. 2透镜越大放得越大 → 决定倍数的是焦距，不是大小
  3. 3焦点只是一个点 → 它也是成像的位置：纸放在焦点附近就有倒像

三层「为什么」

现象层

水滴、放大镜都能放大

规律层

折射 + 曲面 → 汇聚；放大倍数 ≈ 25 厘米 ÷ 焦距

本质层

折射定律；薄透镜公式 1/f = 1/u + 1/v

原理 → 设计决策：要看清细小的东西 → 让光拐弯 → 用曲面的透明材料 → 中间厚、边缘薄 → 焦距越短放得越大。

实验设计

所有实验都在室内、背对太阳做；放大镜买两个焦距不同的。

组 做法 检验什么
A大中小三滴水曲率与放大
B窗外风景成像量焦距焦距
C水杯翻转箭头过焦点成倒像
D两个放大镜比倍数25 ÷ 焦距

操作步骤

  1. A：报纸上铺保鲜膜，用吸管滴大、中、小三滴水，手机从正上方拍。
  2. B：背对太阳，拿放大镜对着窗外远处的楼，在白纸上前后移动到像最清晰，量放大镜到纸的距离。
  3. C：圆玻璃杯装满水，纸上画向右的箭头，放在杯后从近往远慢慢移动，拍箭头翻转的瞬间。
  4. D：用 B 的方法量出两个放大镜的焦距，再隔着它们看同一把尺子，估算一厘米放大成多宽，与「25 厘米 ÷ 焦距」比较。

安全与道具

安全提示
  • 绝不用透镜对着太阳聚光照皮肤、眼睛或可燃物；全程背对太阳。
  • 玻璃杯放稳，防止打碎。
