打水漂

打水漂是世界各地都有的古老游戏，古希腊和中国都有相关记载（拍摄前核对）。石头能在水上弹跳，靠的是扁平、倾斜、旋转三个条件。扁石头贴着水面飞，前端稍稍抬起，触水的只是后缘；石头压着水往前冲，在前面挤起一个小水坡，水对石头的反作用力有一个很大的向上分量，像滑水板一样把它推起来，只要这个力在短暂的接触时间里足以抵消石头向下的速度，石头就又飞起来了。法国科学家用实验发现，石头前端翘起约 20° 时最容易弹起：太平，水坡太小托不住；太陡，一头扎进水里。旋转让石头像陀螺一样保持姿态，角度不会在碰水时乱掉，所以高手都会让石头转着飞出去。每碰一次水都会损失一部分速度，越跳越近、越跳越低，最后沉下去。本集只在浴缸或水盆里用塑料瓶盖做；在户外水边玩要有成年人陪，不朝人扔。

今天

打水漂比赛、滑水板、水上飞机降落、二战弹跳炸弹。

原理

水的反作用力；攻角；陀螺稳定。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1石头是被水弹起来的 → 扁石头斜着、贴着水面飞，前面压起一个小水坡，像滑雪板一样被托起来
  2. 2扔得越用力越好 → 角度最要紧，大约 20° 左右最容易蹦
  3. 3转不转都一样 → 转起来姿态稳，碰水时角度不乱

三层「为什么」

现象层

浴缸里弹塑料瓶盖，比角度、比转不转

规律层

扁的、斜一点、转起来的东西会被水面托起来

本质层

水的反作用力与旋转稳定

原理 → 设计决策：要让一块石头在水上跳得最远 → 选扁平的石头，转着、斜着、贴着水面飞 → 每次碰水都被托起来。

实验设计

场地：浴缸里放约 10 厘米深的水，水面要平静。瓶盖：3 个一样的塑料矿泉水瓶盖（扁的那种），开口朝下。弹法：把瓶盖平放在食指指腹上，手贴近水面（离水面约 3 厘米），拇指和中指扣住，用中指弹出，让它旋转着水平飞出去。角度：平着、前端翘起约 20°、约 60° 三种，每种 5 次，数每次在水面上蹦了几下。不转：用另一只手的手指直接把瓶盖往前推出去（不让它转），20° 弹 5 次。慢动作：手机慢动作贴近水面拍一次碰水。

操作步骤

  1. A：平着弹 5 次，数蹦几下。
  2. B：翘 20°、60° 各弹 5 次。
  3. C：20° 不转弹 5 次。
  4. D：慢动作拍碰水瞬间。
