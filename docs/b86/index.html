冰嬉

冰面滑，是因为冰的表面存在一层极薄、分子排列无序、类似液体的「准液态层」（也称预融层），它在远低于 0 °C 时也存在，使冰面摩擦系数很小。这一层的成因与厚度、它在冰面滑动中起多大作用，至今仍是物理学的研究课题：早年流行的「冰刀压力使冰融化」的解释，经计算在一般温度下压力不足以显著降低熔点，已不被认为是主要原因；摩擦生热融化也有贡献。另一方面，压力确实能让 0 °C 附近的冰融化：挂重物的细铁丝压在冰块上，铁丝下方的冰受压融化，铁丝下移，水绕到上方、压力消失后重新冻结，铁丝最终穿过冰块而冰块不断，这叫复冰现象。清代宫廷每年冬季举行冰嬉，有《冰嬉图》传世。

背景

冰嬉

清代宫廷冬季冰嬉，有《冰嬉图》传世（作者与年代拍摄前核对）。

原理

冰面准液态层；摩擦系数；复冰现象。

争议

冰为什么滑，科学界仍在研究，片中照实说。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1冰天生就滑 → 冰的表面有一层极薄的「像水」的层，摩擦很小
  2. 2冰刀把冰压化了才滑 → 压力的作用很小，主要靠那层表面
  3. 3冰越冷越滑 → 太冷反而没那么滑

三层「为什么」

现象层

弹簧秤拉同一块东西，在冰上和在桌面上比拉力

规律层

冰面薄层降低摩擦；温度影响摩擦

本质层

复冰现象与冰面摩擦

原理 → 设计决策：要在冰上跑得快 → 让接触面窄而光滑 → 穿上冰刀，在冰面上滑。

实验设计

冰面：平底塑料盘或烤盘装 1 厘米深的水，放冷冻室平放过夜。拉力：橡皮用细线系在弹簧秤上，水平匀速拉 20 厘米，读稳定时的数。复冰：一块冰砖（饭盒冻成）架在两个倒扣的杯子上，下面垫毛巾；细铁丝（约 0.5 毫米）跨过冰砖，两头各挂一瓶 500 毫升的水，整套放在地上或矮凳上。冰化的水及时擦干。
