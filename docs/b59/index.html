曲辕犁

牛拉犁时，拉力沿着绳索和犁辕的方向斜向上，可以分解为向前耕地的水平分力和把犁往上提的竖直分力；拉线越陡，往上提的分力越大，犁越容易浮出土、拉力也更多地浪费在「拔犁」上。唐代江东一带的曲辕犁把犁辕做短做弯，挂钩位置低、拉线更平，犁身轻便、转弯灵活，一头牛就能拉；它还有可以调节入土深浅的犁评、犁箭，以及把切下的土条翻转过来的犁壁，使杂草被埋在下面、下层土翻上来。陆龟蒙《耒耜经》详细记载了它的部件。

暂定标题为什么犁辕要做成弯的？
时长约 3 分 36 秒 · 13 个镜头
时代唐 · 陆龟蒙《耒耜经》
衔接← 42 马轭、29 轮作固氮；→ 第十六季特辑

背景

直辕犁

汉代多用长直辕犁，常见「二牛抬杠」（拍摄前核对）。

曲辕犁

唐代江东犁，陆龟蒙《耒耜经》记有犁铧、犁壁、犁底、压镵、策额、犁箭、犁辕、犁梢、犁评、犁建、犁盘十一个部件（名称拍摄前核对）。

原理

力的分解：F 水平 = F cos θ，F 竖直 = F sin θ；犁壁的曲面使土条翻转。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1弯的只是好看 → 弯辕短而轻，拉力方向更合适，转弯灵活
  2. 2犁越重越好 → 合适的角度和犁壁比重量重要
  3. 3犁只是在地上划一道 → 犁壁把土整个翻过来

三层「为什么」

现象层

模型犁拉线角度不同，拉力不同

规律层

拉力方向与分力；犁壁把土翻过去

本质层

力的分解与入土深度

原理 → 设计决策：要省牛力又耕得深 → 缩短犁辕、改变拉力方向 → 加犁壁翻土 → 加犁评调深浅。

实验设计

沙盘：大托盘铺 5 厘米湿沙并压平；模型犁：硬纸板剪犁铧（三角形）和犁壁（弯成弧形的卡纸条），冰棍棒做犁辕，做「长直辕」和「短曲辕」两种。弹簧秤量程 5 牛左右即可。沙面撒一层彩色纸屑当「杂草」。

操作步骤

  1. A：用量角器摆好拉线角度，匀速拉 30 厘米，读弹簧秤平均读数，量沟深；每个角度 3 次。
  2. B：同一角度，装犁壁和不装各拉一次，拍纸屑有没有被埋。
  3. C：两种模型犁各在沙盘里转 90 度，量需要的转弯半径。
  4. D：有条件时去农耕博物馆拍真犁的部件。
