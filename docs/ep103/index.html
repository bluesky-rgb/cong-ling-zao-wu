无线充电

无线充电利用电磁感应：充电板中的发射线圈通以高频交流电，产生不断变化的磁场；手机中的接收线圈处在这个变化的磁场里，就感应出交流电，经整流后给电池充电。它相当于把变压器的铁芯拿掉、两组线圈分开放置，因此耦合程度随距离和对准情况迅速下降，手机需放正、贴近。用手机耳机口输出的音频电流驱动一个线圈，另一个线圈接小喇叭，就能听到音乐「隔空」传过去，原理与无线充电相同，且只用到手机本身的微弱电流。

暂定标题手机放在板子上，没插线怎么就充上电了？
时长约 3 分 36 秒 · 13 个镜头
时代1831 年法拉第 · 2008 年 Qi 标准
衔接← 75 变压器与交流电、56 电磁铁；→ 104 3D 打印

背景

法拉第

1831 年发现电磁感应（接第 4 集磁生电）。

特斯拉

1890 年代做无线输电实验（拍摄前核对）。

Qi

2008 年无线充电联盟成立，随后发布 Qi 标准（年份拍摄前核对）。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1电是从空气里「飞」过去的 → 变化的磁场在接收线圈里感应出电流
  2. 2离多远都行 → 离开几厘米就弱得多
  3. 3什么都能放上去充 → 金属片会发热，所以不能放钥匙硬币

三层「为什么」

现象层

手机音乐从一个线圈「跳」到另一个线圈的耳机里

规律层

变化的磁场感应电流：没有铁芯的变压器

本质层

耦合、距离与频率

原理 → 设计决策：要不插线传电 → 两个线圈对着放 → 下面通交流电，上面就感应出电。

实验设计

漆包线（0.3 毫米左右）在纸杯外各绕 30–50 圈，用胶带固定，两端用砂纸刮掉漆。发射线圈接手机耳机转接线（3.5 毫米插头剪开取左声道和地线），接收线圈接一只 8 欧小喇叭或旧耳机。只用手机音频输出，不接市电、不接功放。

操作步骤

  1. A：两线圈贴近、拉开 1、3、5 厘米，听音量（可用另一部手机分贝 App）。
  2. B：中间夹书、手、铁片各听一次。
  3. C：对齐、错开半个、错开一整个、垂直放各听一次。
  4. D：拍家里无线充电板放正和放歪的区别。

安全与道具

安全提示
  • 只用手机音频输出驱动线圈，不接市电，不接功放；音量别开太大。
  • 刮漆用砂纸，剪线由成年人操作。
  • 真充电板上别放钥匙、硬币等金属，会发热。
