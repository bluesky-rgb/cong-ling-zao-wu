# 决定记录

1. **先做横屏长视频，再拆短视频。** 长视频适合讲清理解过程，短视频负责引流。
2. **先把一集做精，作为模板。** 选了第 04 集「磁生电」：钩子最强，也最能体现「先打破误解」的方法。
3. **所有方案改用网页或 PDF。** 可编辑文档在 iPad 版 Claude App 里打不开。
4. **第一卷定在北宋，约公元 1090 年。** 沈括已记录磁针指南和磁偏角，电磁感应要到 1831 年才被发现。北宋时锌难得，电堆改用铁片。
5. **实验镜头必须实拍，AI 只做氛围。** 科普的实验镜头是证据，生成的画面既可能出错，也等于伪造。
6. **原理动画用代码渲染，而不是视频模型。** 磁感线根数、电压曲线按公式计算，准确且能精确修改。
7. **修正史实。** 法拉第从 1825 年起就在琢磨这个问题，1831 年才做成，而不是「花了几个月」。
8. **成片可能只有 6–7 分钟。** 旁白念完约 4 分半，最终以实际录音为准。
9. **由 Claude 负责拼接成片。** 作者只需要拍实验和准备配音。
10. **增加 B 线「古法解密」。** 古人已经做到、今天却很少有人懂的技艺，讲清楚原理同样有价值；原来的「时代穿帮」选题有了去处。
11. **指南鱼不替观众下结论。** 学界对磁化来源有争议（地磁场还是铁钳），用四组对照实验检验，三种结果各备一段旁白。
12. **公开发布到 GitHub Pages。** 解决了网页私有、观众打不开链接的问题。
13. **理论先行，实践在后。** Claude 把全系列的构想和方案做完整；作者按需要逐集动手验证，根据真实结果调整旁白后再发布。
14. **按第一季顺序把拍摄包备齐。** 先补完第一卷（01、02、03、05），用 kit.py 把问题卡、资料卡、占位画面、粗剪和拍摄本网页做成可复用的流程，后续各集只需写内容和原理动画。
15. **所有「不确定的数字」都留给实测。** 例如铁铜电堆每组电压，动画里只写「每组电压 V（待实测）」，旁白用括号标出要按实测改写的地方。
16. **口感这类「常见说法」也要实测。** 查证发现，卤水豆腐偏老、石膏豆腐偏嫩的说法并不绝对，老嫩主要取决于压掉多少水；动画和旁白只讲机理，口感留给实测。
17. **落差实验用高处水桶，不用水龙头。** 自来水自带水压，水龙头出水的「落差」不是真正的落差；用虹吸水管从不同高度的水桶引水，才能单独检验落差的作用。
18. **土豆电池改成萝卜和橘子。** 马铃薯明代以后才传入中国，北宋设定下用萝卜、橘子、铁钉和铜钱；土豆只作现代对照。
19. **特辑排名不预设。** 第一季特辑只备好结构、回顾动画和打分表，排名和旁白等 11 集实测完、由作者打分后再写。
20. **第二季从「制盐」开篇。** 直接接上第一季结尾的卓筒井，而且能在家做；高危工艺（熔炼、强碱）只用动画或去非遗工坊拍。
21. **炼铜加一个在家能做的版本。** 北宋的「胆水浸铜」（铁置换硫酸铜里的铜）安全可控，作为火法炼铜的对照。
22. **有争议的定义直接摆出来。** 「瓷器从哪年算起」中西方标准不同（东汉成熟青瓷 vs 唐以前称原始瓷），资料卡里两种说法并列，不替观众选。
23. **需要时间的实验提前开工。** 醋酸发酵约两周、糯米灰浆约一个月，拍摄本里标明「建议提前开始」，可以和其他集并行。
24. **第二季的主线是温度。** 特辑用「温度阶梯」把 12 集串起来，说明燃料、鼓风、炉窑、耐火材料四样必须一起进步。
25. **第三季从「提水」开篇。** 同一个水轮，第一季用来发电、第二季用来鼓风，第三季用来提水；大多数实验用塑料瓶、软管、花盆就能在家做。
26. **饮水类选题只做原理演示。** 净水一集所有水样都不饮用，旁白明确「不能代替正规的饮用水处理」，并提醒最可靠的仍是烧开水。
27. **第三季用「一滴水的旅程」收尾。** 提、引、分、省、养、净、冷、过，把 11 集串成一条线；嫁接改用仙人掌，两周就能看到结果，不必等果树。
28. **第四季「救命的知识」规矩更严。** 涉及人体、毒物、有害气体的内容只讲原理和历史，不做人体实验、不给剂量和配方，实验用的食物一律不入口；口服补液、种痘、煤气中毒只用动画。
29. **新增 B19「银钗验毒」。** 《洗冤集录》的银钗正好说明「古人的经验有用，但测到的东西和他们以为的不一样」；用鸡蛋黄代替任何真实毒物。选题总数从 68 个变为 69 个。
30. **看不见、不能做的，用类比实验。** 口服补液用土豆条、去壳蛋、软糖演示渗透；种痘用橡皮泥模具类比免疫记忆、多米诺类比群体免疫，旁白里说明「这只是比方」。
31. **危险气体只拍「旁证」。** 煤气中毒一集绝不在室内点炭、不制造一氧化碳；实拍只用冷勺积黑说明燃烧不完全、罩蜡烛说明缺氧、纸箱线香说明通风，中毒过程全部用动画。
32. **第五季「机械与交通」用纸板和五金件。** 杠杆、滑轮、常平架、曲柄都能用直尺、硬币、纸板、曲别针和五金店的小滑轮做；主线是「省力就要费距离」。被中香炉的模型里只放水，绝不点香。
33. **指南车讲两种复原方案。** 《宋史》记载的燕肃指南车用绳索重锤控制的离合齿轮，差动齿轮是 20 世纪以来的复原思路；片中把两种都讲清楚，并说明原物没有留下。
34. **有争议的说法照实讲。** 「古代颈带会勒住马」来自 20 世纪初的复原实验，后来被更准确的复原质疑；片中标明「此说有争议」。所有拉、勒的实验只用海绵和纸板马，不对动物做实验。
35. **热气球不用明火，帆船实验电器远离水。** 不放孔明灯；风扇放在浴缸外台面或用电池风扇。
36. **第六季用手机当测量仪器。** 秒表数摆、频谱 App 测编钟和鱼洗的音高、录音看余音，把「听起来不一样」变成数字。
37. **测地球要找人配合。** 第 47 集需要另一座城市（南北相距 300 公里以上更好）的朋友同一天测正午影长；温度计第二个定点用 60 ℃ 热水加厨房温度计，避免沸水。
38. **按作者建议新增 E51「青霉素」。** 归入「救命的知识」卷，选题从 69 个变为 70 个。看点是「发现容易，提纯和量产难」；不在家培养细菌，霉菌只拍密封袋里自然长出的，抑菌圈去实验室拍或只用动画，片中说明自制霉菌不能当药、抗生素对病毒无效。
39. **第七季「补全科技树」收官。** 把剩下的 10 个选题（6 种发电方式、煤与焦炭、玻璃、青霉素）排进最后一季，做完全部 70 个选题；最后以全系列特辑收尾。
40. **第七季发电三集只求「趋势对」。** 风车、脚踏、重锤都用 3–6 伏玩具电机当发电机，损耗大，实测不必正好是三次方或 200 焦耳；拍摄本里写明以实测为准，把差距本身讲成「效率」的一课。
41. **热电实验用开水和冰水，不用火。** 铜—铁热电偶在高温下电压会变小甚至反向，读数不稳；开水 / 冰水的温差固定在约 100 ℃，安全又能画出直线。蜡烛只作为成年人操作的「反转」彩蛋。
42. **玻璃用糖来演示。** 真玻璃要上千度、碎片锋利，家里不做；糖浆快冷成透明「糖玻璃」、慢冷加晶种会发白结晶，敲碎也会变白，原理和玻璃、沙子一一对应。实验用糖不食用。
43. **青霉素一集的边界。** 在家只做密封长霉（不开封）、气球网兜和色素稀释；抑菌圈由学校老师用教学菌株和商品药敏纸片做，我们只拍结果，或只用动画。片中必须出现：抗生素遵医嘱使用、对病毒无效、过敏者不能用、自己长的霉绝不能当药。
44. **规划阶段收官。** 70 个选题、7 季特辑的拍摄包全部完成。之后 Claude 的工作转为「按实测回填」：作者发来记录表或打分表，改写旁白、生成排名和口播稿；新选题照旧先进选题库再排季。
45. **先试播 3 集再定顺序。** 04 磁生电 → B1 指南鱼 → 01 摩擦起电，三集道具都在家里；发布一周后看数据再决定先拍哪一季。
46. **查不到出处的说法不进成片。** 古籍原文以维基文库或点校本为准；网上只有转引、找不到原书的（如《鸡肋编》「尽仰石炭」）改用可查证的说法，或在片中用「据记载」。
47. **实拍素材不进仓库。** 仓库只放渲染的动画与粗剪（约 480 MB）；实拍原片和成片放网盘或视频平台，仓库只放链接；`.gitignore` 挡住常见的原片格式。
48. **七季之后「一主一副一特别」。** 主线做科技树第二层，规则是每集至少组合两个已点亮的节点；副线把 B 线独立成 2.0；每年一季换时代特别篇（汉代、1800 年、石器时代）。现在只列候选，不做拍摄包，试播 3 集后看 A、B 两线的数据再定先做哪条。
49. **第八季先做第二层主线「光与电」。** 作者确认三个方向都要尝试；按「一主一副一特别」先推进主线。光学链（透镜、显微镜、望远镜、照相）在家最好拍，排在前面；电灯、蓄电池只用动画。
50. **交付以 GitHub 部署为准。** 每批完成的标准是：提交推送到 main，且 GitHub Pages 的「pages build and deployment」运行成功；汇报时给出线上网址，不再另发预览页面。
51. **并入仓库时只插入导航链接。** 旧的整合脚本会整体重写导航，会冲掉后加的排期、发布素材等链接；从 integrate_s8a.py 起改为在原导航里插入新链接。
52. **第九季做副线「古法解密 2.0」。** 按「主线一季、副线一季交替」，第八季（第二层 · 光与电）之后排 B 线 2.0，候选见内容架构页；先做在家最好拍的公道杯、欹器、长信宫灯。
