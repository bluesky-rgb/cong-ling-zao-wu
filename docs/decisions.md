# 决定记录

1. **先做横屏长视频，再拆短视频。** 长视频适合讲清理解过程，短视频负责引流。
2. **先把一集做精，作为模板。** 选了第 04 集「磁生电」：钩子最强，也最能体现「先打破误解」的方法。
3. **所有方案改用网页或 PDF。** 可编辑文档在 iPad 版 Claude App 里打不开。
4. **第一卷定在北宋，约公元 1090 年。** 沈括已记录磁针指南和磁偏角，电磁感应要到 1831 年才被发现。北宋时锌难得，电堆改用铁片。
5. **实验镜头必须实拍，AI 只做氛围。** 科普的实验镜头是证据，生成的画面既可能出错，也等于伪造。
6. **原理动画用代码渲染，而不是视频模型。** 磁感线根数、电压曲线按公式计算，准确且能精确修改。
7. **修正史实。** 法拉第从 1825 年起就在琢磨这个问题，1831 年才做成，而不是「花了几个月」。
8. **成片可能只有 6–7 分钟。** 旁白念完约 4 分半，最终以实际录音为准。
9. **由 Claude 负责拼接成片。** 作者只需要拍实验和准备配音。
10. **增加 B 线「古法解密」。** 古人已经做到、今天却很少有人懂的技艺，讲清楚原理同样有价值；原来的「时代穿帮」选题有了去处。
11. **指南鱼不替观众下结论。** 学界对磁化来源有争议（地磁场还是铁钳），用四组对照实验检验，三种结果各备一段旁白。
12. **公开发布到 GitHub Pages。** 解决了网页私有、观众打不开链接的问题。
13. **理论先行，实践在后。** Claude 把全系列的构想和方案做完整；作者按需要逐集动手验证，根据真实结果调整旁白后再发布。
