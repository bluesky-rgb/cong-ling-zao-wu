鹰眼

网球落在边线附近，速度每小时一两百公里，人眼常常看不清是压线还是出界。「鹰眼」系统在球场四周装十来台高速摄像机（拍摄前核对）。一台摄像机拍到球，只能知道球在「从这台相机出发、穿过画面上那个点」的一条直线上，但不知道在这条线上的哪里；另一台从别的方向拍，又得到一条线，两条线的交点就是球在空间里的位置——这叫三角测量，和第 90 集卫星定位用几个距离算位置是同一类道理。每台相机都有一点误差，画出来的其实是一条有宽度的「带子」，相机越多、方向分得越开，这些带子交出来的那一小块就越小，误差就越小，据称能到几毫米（以资料为准）。电脑把每一帧算出的位置连起来，就得到球的飞行轨迹和落点。21 世纪初网球比赛开始使用，后来足球、排球也有类似系统（拍摄前核对）。本集弹珠别让小孩放进嘴里。

暂定标题网球落在线边上，人眼看不清，「鹰眼」系统是怎么算出球到底压没压线的？
时长约 3 分 36 秒 · 13 个镜头
时代21 世纪初网球比赛开始用多台摄像机判断出界
衔接← 95 数码相机、90 卫星定位；→ 211 蹦床

背景

出现

21 世纪初网球比赛开始用多台摄像机判断出界（拍摄前核对）。

今天

网球鹰眼、足球门线技术、动作捕捉、测绘、双目相机测距。

原理

三角测量；视线交会；误差与冗余。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1鹰眼是一台超快的相机 → 好几台摄像机从不同角度同时拍，几条视线交在一起才是球的位置
  2. 2摄像机越多越慢 → 越多越准，算出来的是位置和轨迹
  3. 3两台相机靠得近更准 → 方向分得越开越准

三层「为什么」

现象层

两人从两个方向瞄弹珠画线找交点

规律层

两条视线的交点确定位置

本质层

三角测量

原理 → 设计决策：要在一瞬间判断球压没压线 → 从不同角度放好几台摄像机 → 几条视线交在一起，算出球的位置。

实验设计

场地：一张 A3 白纸用胶带四角贴牢在桌上。球：一颗弹珠放在纸上任意位置，用铅笔在它底下轻轻圈一个小圈做记号（弹珠拿开后能看到）。瞄：甲站在桌子左边，把一把长尺子平放在纸边，眼睛贴近桌面，从尺子一端看过去，转动尺子，让尺子的边对准弹珠中心，然后沿尺子边在纸边画一小段线。乙站在桌子前边（和甲的方向差不多成直角），做同样的事。交：拿走弹珠，用尺子把两小段线延长到纸中间，找到交点，量交点到铅笔小圈中心的距离（毫米）。重复：换 3 个弹珠位置。三人：加丙从另一个方向瞄，看三条线交出的小三角形有多大。近距：让甲乙站在几乎同一个方向瞄，看交点误差。

  3. C：三人瞄，看小三角形。
  4. D：两人几乎同方向瞄，比误差。
