自动驾驶

自动驾驶汽车用传感器代替眼睛、用计算机代替大脑，不断重复「感知—定位—决策—控制」的循环，每秒几十次。感知：摄像头识别车道线、红绿灯、行人和车辆，毫米波雷达测量前后车的距离与速度，激光雷达旋转扫描、生成周围环境的三维点云，超声波雷达探测近处障碍。定位：结合卫星定位、高精度地图、轮速计和惯性测量单元（陀螺仪与加速度计），把自己定位到具体车道上。决策与规划：根据交通规则、导航路线和对周围物体运动的预测，决定加速、减速、变道、停车，并规划出平滑的行驶轨迹；其中大量用到机器学习模型。控制：把规划转换成方向盘转角、油门和刹车指令，由线控系统执行。规则无法穷尽所有情况，遇到从未见过的场景（施工、异常天气、奇怪的障碍）是自动驾驶最难的部分，所以目前大多数系统仍需要驾驶员随时接管，自动驾驶按 L0–L5 分级（拍摄前核对）。2004 年美国国防高级研究计划局举办沙漠无人车挑战赛，首届无车完赛，2005 年第二届有多辆车完成（拍摄前核对）。本集只在纸上做方格迷宫游戏，不在马路上试。

出现

今天

原理

传感器融合；定位；规划与控制。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1自动驾驶车有一个「看懂一切」的大脑 → 它一遍遍地做三件事：看清周围、判断位置、按规则和计划决定动作
  2. 2规则写得越多越安全 → 规则还要能应付没见过的情况
  3. 3有了自动驾驶就不用看路 → 大多数系统仍要驾驶员随时接管

本质层

感知—决策—控制

原理 → 设计决策：要让车自己开到目的地还不撞东西 → 让它不停地看周围、知道自己在哪 → 再按地图和规则一步步决定怎么走。

实验设计

迷宫：在 A4 纸上画 8 × 8 方格（每格 2.5 厘米），用黑笔涂黑一些格子当墙，留出一条从左上角起点到右侧终点的通路（可以照动画画）。角色：「车」拿一枚棋子，闭上眼或背对迷宫；「传感员」每一步只告诉他：前面、左边、右边各有没有墙；「车」只能按规则卡决定下一步，传感员替他挪棋子。规则卡 A：1 右边空就右转并前进；2 前面空就前进；3 左边空就左转并前进；4 都堵就掉头。规则卡 B：把 1 和 3 对调。记录每种规则走到终点的步数或卡住的位置；再放一枚硬币当「新障碍」。
