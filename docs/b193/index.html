吊脚楼

西南山区很早就有干栏式的吊脚楼（拍摄前核对）。在陡坡上盖房子，要把一大片坡挖平太费工；吊脚楼顺着坡来：靠山的一边直接坐在坡上，坡下的一边用长长的木柱撑起来，越往坡下柱子越长，柱顶都在同一个高度，楼板就平了。悬空的下层通风、防潮，还能放农具、关牲口。一排竖柱只负责把重量往下传，从侧面一推，每根柱子都会绕着脚歪过去，像一排立着的筷子；吊脚楼在柱子之间横着穿进一根根「穿枋」，用榫卯把柱子连成一个整体的框，有的再加斜撑，把框分成三角形。三角形三条边定了，形状就定了，推也推不变形，这是房子在山风里站得住的关键。今天的脚手架、高压电塔、桥梁桁架，都靠横杆和斜撑组成三角形。本集用吸管搭模型，剪吸管由大人操作。

暂定标题在很陡的山坡上，吊脚楼一半贴着山、一半用长长的木柱撑在半空，为什么不会塌？

背景

出现

西南山区很早就有干栏式吊脚楼（拍摄前核对）。

今天

脚手架、高压电塔、桁架桥、海边高脚屋。

原理

框架结构；三角形稳定性；顺坡架空。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1柱子越粗越稳 → 要靠横枋和斜撑把柱子连成不变形的框
  2. 2不用横木也能站 → 光有竖柱，侧面一推就歪
  3. 3盖房子要先挖平 → 吊脚楼顺着坡用长短柱撑平，省工又通风

三层「为什么」

现象层

只有竖柱、加横枋、加斜撑三种侧推对比

规律层

竖柱传重量，三角形让框不变形

本质层

框架结构与三角形稳定

原理 → 设计决策：要在陡坡上建平平的房子 → 一边坐在山上，另一边用长柱撑起 → 柱子之间用横枋穿起来，成一个整体的框。

实验设计

斜坡：一块 30×40 厘米的木板或厚纸板，一头用几本书垫高成约 30° 的斜坡，放稳。柱子：吸管由大人剪成长短不同的 4 根，靠坡上的短、坡下的长，让柱顶一样高；柱脚用橡皮泥固定在坡上。楼板：一张卡纸盖在柱顶，用胶带粘住，上面放一块橡皮擦。实验 1：一根手指从侧面轻推楼板约 1 厘米远的距离后松开，用尺子量楼板歪了多少。实验 2：用吸管在柱子中间高度横着把 4 根柱子连起来（胶带粘），再推；再在一面加一根斜着的吸管，再推。实验 4：把斜坡再垫高一些，看小楼还稳不稳。
