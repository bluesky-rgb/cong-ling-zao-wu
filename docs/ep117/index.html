石墨烯

铅笔芯的主要成分是石墨（和黏土），并不含铅。石墨由一层层碳原子组成，每一层中碳原子排成六边形网格，层内电子可以自由移动，所以石墨能导电；层与层之间结合很弱，容易滑开，写字时就一层层蹭到纸上。用 6B 等软铅笔涂得又黑又粗的线是一条导电通路，接上 3 伏电池，电流能点亮 LED；线越长越细，电阻越大，LED 越暗。只有一层碳原子的石墨称为石墨烯，导电导热性极好、强度很高。2004 年海姆和诺沃肖洛夫用透明胶带反复剥离石墨得到石墨烯，2010 年获诺贝尔物理学奖。

暂定标题铅笔芯里的碳，为什么能导电？
时长约 3 分 36 秒 · 13 个镜头
时代2004 年胶带剥离石墨烯 · 2010 年诺贝尔奖
衔接← 102 LED、B32 松烟墨；→ 118 虚拟现实

背景

发现

2004 年安德烈 · 海姆与康斯坦丁 · 诺沃肖洛夫用胶带剥离法得到石墨烯。

获奖

2010 年诺贝尔物理学奖。

原理

石墨层内导电；层间范德华力弱。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1铅笔芯是铅做的 → 是石墨和黏土
  2. 2画在纸上的线不导电 → 涂得够黑够粗，就能点亮 LED
  3. 3越薄越不结实 → 一层原子厚的石墨烯却非常结实

三层「为什么」

现象层

用铅笔在纸上画粗线，接 3 伏电池和 LED

规律层

石墨的层状结构；单层就是石墨烯

本质层

胶带剥离法与二维材料

原理 → 设计决策：要找一种又薄又导电的材料 → 把石墨一层层剥开 → 剥到只剩一层碳原子。

实验设计

6B 或 8B 软铅笔在白纸上反复涂，涂到发亮。3 伏 CR2032 纽扣电池一颗，LED 一颗（长脚接正极），用带鳄鱼夹的导线连接：电池正极 → LED 长脚，LED 短脚 → 铅笔线一端，铅笔线另一端 → 电池负极。夹子夹在铅笔线两端时压紧。纽扣电池用完立刻收好，放在小孩够不着的地方，防止误吞。

操作步骤

  1. A：三条线各接一次，比 LED 亮度。
  2. B：不同铅笔和涂法比亮度（有万用表就量电阻）。
  3. C：胶带反复粘剥 10 次，对光看。
  4. D：画一个带缺口的电路，涂上缺口开灯。

安全与道具

安全提示
  • 只用 3 伏纽扣电池，不接其他电源。
  • 纽扣电池别让小孩拿、别放进嘴里；误吞要立刻就医。
  • 铅笔灰弄到手上及时洗。
道具用途
6B 或 8B 铅笔、HB 铅笔、白纸石墨线
3 伏纽扣电池、LED、鳄鱼夹导线电路
透明胶带剥离
万用表（可选）电阻
