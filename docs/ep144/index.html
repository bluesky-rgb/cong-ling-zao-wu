不锈钢

铁生锈是一种电化学腐蚀：铁原子失去电子变成铁离子，氧气和水在另一处得到电子，最终生成含水的氧化铁（铁锈）。因此生锈需要水和氧同时存在；盐溶于水后增加导电性，加快电子转移，所以盐水中铁锈得更快；涂油、刷漆能把水和氧隔开。铁锈疏松多孔，不能保护里面的铁，腐蚀会一层层向内发展。不锈钢是含铬量较高（通常不少于约 10.5%，拍摄前核对）的铁合金：铬比铁更容易与氧结合，在表面迅速形成一层只有几纳米厚、致密且附着牢固的氧化铬膜，把内部金属与水和氧隔开，这叫钝化；膜被划破后，只要有氧，铬会很快重新形成膜（自修复）。常见的 304 不锈钢含约 18% 铬、8% 镍（拍摄前核对）。不锈钢并非绝对不锈：在含氯离子多的环境（如长期泡浓盐水）中也可能出现点蚀。1913 年英国冶金师布里尔利在研究枪管钢时注意到高铬钢不易生锈（拍摄前核对）。本集的锈水不要喝，做完倒掉。

暂定标题铁钉放几天就锈了，不锈钢勺子为什么不锈？
时长约 3 分 36 秒 · 13 个镜头
时代1913 年布里尔利发现不锈钢
衔接← 18 炼铁、62 钢；→ 145 铝

背景

发现

1913 年布里尔利（拍摄前核对）。

今天

餐具、水槽、手术器械、建筑外墙。

原理

电化学腐蚀；铬的钝化膜；自修复与点蚀。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1不锈钢是没有铁的钢 → 它还是铁，只是加了铬，表面长出一层「保护膜」
  2. 2生锈只要有水 → 要水和氧气一起，盐会让它锈得更快
  3. 3不锈钢绝对不锈 → 长期泡浓盐水也可能出现小锈点

三层「为什么」

现象层

五枚铁钉分别放进清水、盐水、空杯、涂油后放清水、和不锈钢勺一起放盐水，看 5 天

规律层

铁要水和氧才会生锈；铬让表面长出保护膜

本质层

氧化、钝化与电化学腐蚀

原理 → 设计决策：要一种做餐具、手术刀都不会锈的钢 → 在铁里加铬 → 让表面自己长出一层挡住氧气的薄膜。

实验设计

用普通铁钉（不要镀锌的，镀锌钉是银白色、不容易锈）。杯子：透明塑料杯或玻璃杯，各倒 100 毫升水；盐水用 1 小勺盐。D 组铁钉用手指抹一层食用油再放进清水。F 组：成年人把水煮沸 3 分钟赶走部分氧气，放凉后倒入杯中，放钉子后上面倒一层 1 厘米厚的油封住。每天同一时间、同一位置拍照。打分标准：0 = 没锈，5 = 整根锈满。做完把水倒掉、钉子扔掉、洗手。
