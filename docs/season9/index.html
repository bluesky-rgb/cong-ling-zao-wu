第九季特辑 · 古法解密 2.0

回顾第九季 10 集「古法解密 2.0」：十件古物拆成四类原理。流体与压强：公道杯（虹吸）、水密隔舱（浮力）、灵渠陡门（连通器）、唧筒（大气压）、双动活塞风箱（单向阀）；力与机械：欹器（重心）、记里鼓车（齿轮比）；热：长信宫灯、走马灯；信息：交子防伪。再按实测结果给每集打「古法还原度」分。

B21 欹器（重心与吊点）；B25 记里鼓车 ← 41 齿轮、B17 指南车；B22 长信宫灯、B23 走马灯（热气流）；B29 交子防伪 ← B2 活字印刷。

打分依据

材料、难度、效果三项各 1–5 分；效果看实测像不像古书记载。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1古人只是凭经验 → 很多器物背后是一个清楚的原理
  2. 2古物都很难复原 → 多数用家里的东西就能做出模型
  3. 3原理是现代才知道的 → 名字是后来起的，现象古人早就会用

三层「为什么」

现象层

十件古物在家都能做模型

规律层

四类原理：压强、机械、热、信息

本质层

同一个原理连起 A 线和 B 线的节点

原理 → 设计决策：排名不预设结论：先填完打分表，再按分数写旁白。
