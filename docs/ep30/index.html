选种与嫁接

每年挑最好的种子留种，好性状一代代积累；嫁接让两棵植物的形成层长在一起，把好品种原样「搬」到别的根上。

暂定标题不懂基因，怎么改良品种？
时长约 3 分 36 秒 · 13 个镜头
时代北魏《齐民要术》· 北宋
衔接← 29 轮作固氮；→ B6 赵州桥

背景

选种

《齐民要术·收种》：「粟、黍、穄、粱、秫，常岁岁别收，选好穗纯色者，劁刈高悬之。至春治取，别种，以拟明年种子。」并引《氾胜之书》选麦种、禾种的方法。

嫁接

《齐民要术》有专门讲嫁接梨树的篇章，以棠、杜等为砧木。具体原文拍摄前请核对。

遗传

1866 年孟德尔发表豌豆杂交实验，遗传规律至 1900 年才被重新发现。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1品种是天生的 → 一代代挑选就能改良
  2. 2嫁接是把两棵树粘起来 → 是形成层细胞长到了一起
  3. 3嫁接会把两个品种混在一起 → 果子仍是接穗的品种

三层「为什么」

现象层

挑大粒的种子，下一代平均更大；嫁接的枝条结出原品种的果子

规律层

人工选择让有利的变异代代积累；嫁接处的形成层愈合连通

本质层

遗传变异被筛选、积累；接穗保留自己的基因，只借用砧木的根

原理 → 设计决策：要好品种 → 年年挑好穗、单独收、单独种；好品种种子不保真 → 用嫁接无性繁殖；嫁接要成活 → 形成层对齐、绑紧、保湿。

实验设计

仙人掌嫁接最容易成功，四季都可以做（温暖季节更快）。

组 做法 检验什么
A随机 100 粒 vs 最大 100 粒绿豆选种的效果
B量 50 粒豆子画分布图个体差异
C仙人掌平接嫁接成活
D两周后检查、切面特写形成层愈合

操作步骤

  1. A：称重后，两组各取 20 粒，泡一夜，种在同样的土里，记录发芽数和一周后的平均苗高。
  2. B：用尺子或游标卡尺量长度，按 0.5 毫米分组，在纸上画柱状图。
  3. C：两棵柱状仙人掌（如量天尺作砧木，小球仙人掌作接穗），用干净的刀横切，切面对齐，中间的维管束环要重叠；用两根橡皮筋十字交叉固定。
  4. 放在明亮但不暴晒的地方，一周内不浇水，两周后拆掉橡皮筋检查。

  • 精选种子的苗是否明显更壮
  • 仙人掌嫁接的成活率
  • 豆子大小分布是否接近钟形
