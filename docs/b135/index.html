结绳记事

《周易·系辞下》说「上古结绳而治，后世圣人易之以书契」（拍摄前核对），在文字出现以前，人们用在绳子上打结的方法记事记数。最系统的例子是南美印加帝国的「奇普」（quipu）：一根主绳上挂许多垂绳，每根垂绳上按离主绳的远近分成若干段，分别代表万、千、百、十、个位，每段打几个结就表示该位的数字，空位不打结表示零；绳的颜色和挂法还能区分不同类别，用来记录人口、税收和物资（拍摄前核对）。这种方法与算筹一样采用了位值制：同样的结，打在不同位置代表不同的大小。只要记录者和读取者使用同一套规则，没有文字也能准确地保存和传递数字；如果读的人不知道规则，就无从读起，这正是「编码」的含义。本集用毛线制作，剪刀由成年人使用。

原理

位值制；编码规则。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1结越大事越大 → 结的位置和个数表示数目，离主绳近的是大数位
  2. 2一根绳只能记一个数 → 一根主绳上挂许多垂绳，就是一张表
  3. 3谁都能读懂 → 不知道规则就读不出来

三层「为什么」

现象层

毛线打结记年龄，让别人读

规律层

打结的位置就是数位

本质层

计数与编码

原理 → 设计决策：要把收了多少粮、过了多少天记下来 → 在绳子上打结 → 规定不同的位置代表不同的数位。

实验设计

主绳：一根约 50 厘米长的粗毛线，两端系在两把椅子上拉直。垂绳：4 根约 30 厘米长的毛线，等距系在主绳上。规则：垂绳上离主绳 5–15 厘米一段为十位，20–30 厘米一段为个位；每打一个单结代表 1。记录：按规则把 4 个家人的年龄分别打在 4 根垂绳上（剪线由成年人帮忙）。读取：把绳子交给另一人，只告诉他规则；再找一个不知道规则的人试读。

操作步骤

  1. A：4 根垂绳按规则打结。
  2. B：告诉规则后请人读。
  3. C：不告诉规则请另一人读。
  4. D：加一根垂绳记这个月的雨天。
