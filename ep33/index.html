防坏血病

1747 年林德的对照实验发现柑橘能治坏血病；病因是缺维生素 C，没有它，身体做不出结实的胶原蛋白。

暂定标题史上最早的对照实验之一
时长约 3 分 36 秒 · 13 个镜头
时代1747 年 · 索尔兹伯里号 · 林德
衔接← 32 洗手；→ B19 银钗验毒

背景

林德的实验

1747 年 5 月，英国军舰索尔兹伯里号上，林德挑了 12 个坏血病水手，两人一组：苹果酒、稀硫酸、醋、海水、橙子和柠檬、大蒜芥末糊剂。只有柑橘组很快好转。

迟来的采纳

1753 年出版《论坏血病》；1795 年英国海军才开始每天配发柠檬汁。

维生素 C

1928 年前后被分离出来，随后确认就是维生素 C。它参与胶原蛋白的合成。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1坏血病是瘴气或懒惰引起的 → 是缺一种营养
  2. 2哪种酸都行 → 醋和稀硫酸都不管用
  3. 3果汁放多久都一样 → 维生素 C 怕热、会慢慢氧化

三层「为什么」

现象层

吃柑橘的水手好了，其他组没有

规律层

对照实验：只改一个条件，其他保持相同

本质层

维生素 C 参与胶原蛋白的修饰，缺了它胶原蛋白不稳定

原理 → 设计决策：要证明是柑橘起作用 → 病情相近、伙食相同、只换一样；要在家比较维生素 C → 碘淀粉滴定，数滴数。

实验设计

碘淀粉滴定只用来比较多少，不算准确含量；所有液体都不入口。

组 做法 检验什么
A碘淀粉液 + 维生素 C 片滴定原理
B橙汁、柠檬汁、苹果汁、清水谁的维生素 C 多
C鲜榨、煮沸、放一天加热和放置
D干绿豆 vs 豆芽发芽前后

操作步骤

  1. 配蓝色液：一小勺淀粉（或米汤）兑一杯水，滴几滴碘酒，搅成均匀的蓝色；每次取同样多（如 20 毫升）。
  2. A：把维生素 C 片溶在水里，滴一滴，看蓝色褪去。
  3. B：用滴管逐滴加果汁，每滴后搅拌，记下蓝色完全褪去时的滴数；滴数越少，维生素 C 越多。
  4. C：同一个橙子榨汁分三份：立即测、煮沸 10 分钟后放凉测、室温放一天再测。
  5. D：绿豆泡水发芽三天（第 30 集剩下的绿豆即可），和泡了一夜的干豆分别捣碎取汁测。

安全与道具

安全提示
  • 碘酒不可入口，用完洗手。
  • 实验用的果汁都不喝。
  • 煮沸时注意烫伤。
  • 本集只讲历史和原理，不涉及任何补充剂的用量建议。
