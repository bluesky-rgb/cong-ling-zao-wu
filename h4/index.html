五铢钱电堆

把第 02 集伏打电堆退回汉代：电池需要两种活泼程度不同的金属和一种导电液体。汉代有铜（五铢钱是铜合金）、铁、铅、锡，却没有金属锌（中国大量炼锌要到明代），所以只能用铜配铁。铜铁盐水电池一节只有零点几伏，约为铜锌的一半；叠十节，电压加到四伏左右，但内阻大、电流很小。把导线绕成线圈放在罗盘旁，针会偏转：电生磁在汉代条件下也看得见。

暂定标题汉代人有没有可能做出电池？
时长约 3 分 36 秒 · 13 个镜头
时代汉 · 五铢钱（公元前 118 年起铸）
衔接← 02 伏打电堆、03 电生磁；→ H5 铅钡琉璃

背景

五铢钱

汉武帝元狩五年（公元前 118 年）始铸五铢钱，铜合金，常含铅、锡（成分拍摄前核对）。

金属

汉代冶铁已普及；锌因沸点低、难以用普通冶炼得到，中国大量生产金属锌一般认为在明代（拍摄前核对）。

原理

两种金属在电解液中的电极电位不同，就有电压；串联时电压相加，电流受内阻限制。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1电池要现代材料 → 铜和铁加盐水就行
  2. 2电压低就没用 → 叠起来电压相加
  3. 3电压够了就能点灯 → 还要看电流：内阻太大

三层「为什么」

现象层

铜钱和铁片夹盐水布有电压

规律层

金属活泼性不同产生电压；串联相加

本质层

内阻与电流；汉代缺锌的原因

原理 → 设计决策：第 02 集的电堆 → 换成汉代能找到的金属 → 测一节 → 叠十节 → 用罗盘看见电流。

实验设计

用仿古铜钱或铜垫片（不要用真古钱，收藏品会被腐蚀）；铁垫片用砂纸磨亮；布片剪成比钱略小的圆，浸盐水后挤到不滴水。

组 做法 检验什么
A一节铜铁 vs 一节铜锌金属组合
B盐水 / 醋 / 草木灰水电解液
C1 到 10 节逐节叠串联
D线圈 + 罗盘电流

操作步骤

  1. A：铜钱 + 盐水布 + 铁垫片做一节，万用表直流电压档测；再用铜片 + 锌片（锌垫片或镀锌垫片）测一节对比。
  2. B：同一组铜铁，分别用盐水、白醋、草木灰水浸布，各测一次。
  3. C：按铜 / 布 / 铁的顺序逐节叠，每加一节测一次，记到 10 节；最后在暗处接一个红色 LED（长脚接铜端）。
  4. D：漆包线在罗盘外绕 20 圈，罗盘针先对准南北、线圈与针平行，两端接电堆，看针偏转，断开再看。

安全与道具

安全提示
  • 电压很低，安全；但盐水会让铁生锈、弄脏桌面，下面垫托盘。
  • 不用真古钱。
  • 用完把铜钱、铁片擦干，盐水布丢掉。
