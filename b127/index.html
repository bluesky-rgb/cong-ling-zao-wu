谢公屐

据《宋书·谢灵运传》记载，南朝诗人谢灵运好游山，「登蹑常着木屐，上山则去前齿，下山去其后齿」，后人称为谢公屐，李白诗中有「脚著谢公屐」之句（拍摄前核对）。木屐底下有前后两道齿，在平地上鞋底水平。人在斜坡上行走时，若前后齿等长，鞋底随坡面倾斜：上坡时脚尖高、脚跟低，踝关节被迫背屈、小腿后侧持续拉紧，重心容易往后倒；下坡时脚尖低、脚跟高，重心容易向前冲。去掉朝坡上方那一端的齿（上山去前齿、下山去后齿），两端支点的高度差抵消了坡面的落差，鞋底重新接近水平：脚掌受力均匀，重心落在支撑面内，站得稳、走得省力。齿的长度与坡度有关：设前后齿间距为 d、坡角为 θ，需要抵消的高度差约为 d·sinθ。本集用小木块和筷子在斜木板上演示，不穿真木屐上下坡。

暂定标题上山时取掉前齿、下山时取掉后齿，这双木屐为什么能让人在山坡上走得稳？
时长约 3 分 36 秒 · 13 个镜头
时代南朝谢灵运的登山木屐
衔接← B75 水准、B113 高跷；→ B128 簧片锁

背景

记载

《宋书·谢灵运传》（拍摄前核对）。

今天

登山杖、坡道上的可调脚垫、相机三脚架的可调腿。

原理

水平与倾角；重心与支撑面。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1木屐的齿是为了防滑 → 齿的长短让脚底在斜坡上也保持水平
  2. 2上下山都一样走 → 上山脚底朝后倒，下山朝前倒，要分别垫
  3. 3拆哪个齿都行 → 要拆朝坡上方那一头的齿

三层「为什么」

现象层

小木块当鞋底放在斜板上，拆不同的齿读倾角

规律层

把斜坡「垫平」，脚底保持水平

本质层

水平面与支撑

原理 → 设计决策：要在陡坡上站得稳走得省力 → 让脚底保持水平 → 把木屐的齿做成能拆的，上山拆前齿、下山拆后齿。

实验设计

斜坡：一块长约 40 厘米的木板或硬纸板，一头垫几本书，用手机量角器或水平仪 App 调到约 15°。鞋底：一块火柴盒大小的木块（或橡皮）。齿：两段同样长（约 2 厘米）的筷子，用橡皮泥竖直粘在木块底下的前后两端。测量：把手机水平仪 App 平贴在木块上面读角度（或在木块上放一个小水平泡）。不穿真木屐上下坡。

B上山拆前齿保持水平

操作步骤

  1. A：等长两齿，读倾角。
  2. B：朝上坡放，拆前齿读倾角。
  3. C：朝下坡放，拆后齿读倾角。
  4. D：倾角 0 与 15° 时各放硬币，轻敲木板。
