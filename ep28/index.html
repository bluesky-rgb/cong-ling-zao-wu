水车提水

翻车用一串刮板把水一节节推上斜槽，靠人踩；筒车立在河里，靠河水推动，让竹筒在下面灌满、在顶上倒出。

暂定标题水只会往低处流，怎么把它送上田埂？
时长约 3 分 36 秒 · 13 个镜头
时代东汉翻车 · 唐代筒车 · 北宋
衔接← 06 水车发电、B4 水排；第三季开篇

背景

翻车

东汉毕岚发明，三国马钧改进推广，又称龙骨水车，是刮板式连续提水机械，被认为是中国古代链传动的最早应用之一；可用人力、畜力、水力或风力驱动。

筒车

唐代前期出现，又称天车：立式水轮、竹筒、支架和水槽组成，河水冲动水轮，竹筒取水倒入水槽，实现自流灌溉。

能量

提水所需的功 = 水的重量 × 提升高度；筒车用的是河水的动能，所以只能把一部分水抬高。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1水只能往低处流 → 水流推动轮子，斗把水带上去
  2. 2轮子越大越好 → 提得越高，每分钟提的水越少
  3. 3筒车是自己转的永动机 → 它用的是河水的能量

三层「为什么」

现象层

翻车、筒车把水从河里送上田埂

规律层

提升的势能来自人力或河水的动能

本质层

能量守恒：大量水的动能 → 少量水的势能

原理 → 设计决策：人力有限 → 用脚踩，力气更大；不想用人 → 让河水推动（筒车）；要提得高 → 更大的轮子或更长的槽，代价是更费力。

实验设计

模型用塑料槽、绳子、卡片、纸盘、小纸杯；在水池或浴缸边做。

组 做法 检验什么
A自制翻车：塑料槽 + 刮板绳刮板提水
B翻车倾角 20° / 35° / 50°高度与水量的取舍
C自制筒车放在水流下水力自动提水
D测筒车每分钟提水量和高度能量的账

操作步骤

  1. 翻车：塑料线槽或半截水管当槽，长约 60 厘米；绳子上每隔 5 厘米粘一张略窄于槽的硬卡片。
  2. 槽的下端泡进水盆，上端架在高处的接水盒上，匀速拉绳 1 分钟，量接到的水。
  3. 筒车：直径 20 厘米的纸盘（或旧自行车轮）边缘斜绑 8–12 个小纸杯，轴穿一根筷子架起来，让水龙头的水冲在轮子一侧。
  4. 在轮子顶部偏一侧放一个接水槽，调整杯子的倾斜角度，让它们刚好在顶上倒水。

安全与道具

安全提示
  • 在水池或浴缸边操作，注意地面防滑。
  • 用自行车轮时注意辐条夹手。
道具用途
