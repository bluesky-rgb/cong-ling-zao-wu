近视眼镜

眼睛像一台照相机：角膜和晶状体组成会聚透镜，把外界的光聚焦到眼底的视网膜上成像。看远处时，来自远处物体的光近似平行。近视多数是因为眼轴（眼球前后长度）偏长，或角膜、晶状体屈光力过强，平行光在到达视网膜之前就已聚焦，到视网膜上变成模糊的光斑，所以远处看不清。近视眼镜是凹透镜，中间薄、边缘厚，使光线先略微发散，等效于远处的物体「移近」了，眼睛再聚焦时焦点后移，正好落在视网膜上。远视（眼轴偏短）和老花（年龄增大后晶状体调节能力下降，看近处吃力）则用凸透镜，帮助眼睛把光多会聚一些。眼镜度数约等于镜片屈光度的 100 倍，例如 -3.00 屈光度即近视 300 度（以资料为准）。眼镜约在 13 世纪出现于意大利，明代传入中国，称「叆叇」（拍摄前核对）。本集用装水的圆形花瓶模拟眼球，只做光学演示，配镜请到正规机构验光。

暂定标题近视的人戴上眼镜，为什么远处就看清了？
时长约 3 分 36 秒 · 13 个镜头
时代13 世纪眼镜 · 明代「叆叇」
衔接← 52 透镜、55 照相；→ 135 X 光

背景

起源

13 世纪末意大利出现眼镜（拍摄前核对）。

中国

明代传入，称「叆叇」（拍摄前核对）。

原理

屈光；眼轴与焦点；凹透镜与凸透镜矫正；度数与屈光度。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1近视是眼睛「看不远」所以要放大 → 焦点落在视网膜前，凹透镜让光先散开一点
  2. 2度数越高越好 → 度数要刚好，配镜要验光
  3. 3近视镜和老花镜一样 → 一个是凹透镜，一个是凸透镜

三层「为什么」

现象层

装水的圆花瓶当眼球，后面白纸当视网膜，看远处窗户的像清不清楚，再在前面加凹透镜

规律层

晶状体聚光；焦点落在哪里决定清不清

本质层

屈光、焦距与矫正

原理 → 设计决策：要让近视眼看清远处 → 在眼前加一片中间薄、边缘厚的镜片 → 让光先散开，再由眼睛聚到视网膜上。

实验设计

「眼球」：一个圆形玻璃花瓶或球形鱼缸（直径 10–15 厘米），装满清水，放在桌上稳当处，正对明亮的窗户（不对着太阳）。「视网膜」：一张白卡纸竖在瓶后，前后移动找最清楚的倒像，用尺子量距离。镜片：家里的近视眼镜和老花镜（或文具店的凹透镜、凸透镜）。在较暗的房间里对着亮窗户效果最好。

组 做法 检验什么
A找最清楚的像聚焦
B白纸后移 + 近视镜片近视与矫正
C白纸前移 + 两种镜片远视与矫正
D报纸上看字大小区分两种镜片

操作步骤

  1. A：移动白纸找最清楚的倒像，量距离。
  2. B：白纸后移 3 厘米，加近视镜片对比。
  3. C：白纸前移 3 厘米，分别试近视镜片和老花镜片。
  4. D：两种眼镜放报纸上看字变大还是变小。

安全与道具

安全提示
  • 玻璃花瓶放稳，装水后别搬动；不对着太阳聚光，花瓶旁不放纸张。
  • 本集只做光学演示，不代替验光；视力问题请到正规医院或验光机构。
