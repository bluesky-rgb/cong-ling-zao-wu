九连环

九连环的规则决定了每次只能移动一个环：最前端的环可以随时上下；其他环只有在它紧前面的一个环在杆上、而更前面的环全部不在杆上时才能移动。要解下第 n 个环，必须先把前 n−2 个环解下、把第 n−1 个环留在杆上，因此步数满足递推关系，每多一个环步数约翻一倍，9 个环按单环计数需要 341 步（不同计步法结果不同）。把每个环在杆上记作 1、不在记作 0，解环过程中相邻两个状态只相差一位，这正是今天数字电路和编码器中广泛使用的格雷码。

背景

历史

九连环在中国流传已久，宋代已有记载（出处拍摄前核对）；欧洲称为「中国环」。

数学

19 世纪法国人格罗斯用二进制分析九连环（拍摄前核对）；1947 年贝尔实验室的格雷申请了使用反射二进制码的专利，后称格雷码。

原理

递推 a(n) = a(n−1) + 2a(n−2) + 1；n 为奇数时 (2ⁿ⁺¹ − 1) / 3，偶数时 (2ⁿ⁺¹ − 2) / 3。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1多一个环多几步 → 每多一个环步数差不多翻一倍
  2. 2乱试就能解 → 有一条固定的路
  3. 3只是玩具 → 它的步骤正是格雷码

三层「为什么」

现象层

解开 1、2、3 个环各要几步

规律层

递推：解第 n 个要先解前面的

本质层

格雷码与 2 的幂

原理 → 设计决策：要做一个难解的玩具 → 让每一步都依赖前面 → 步数指数增长。

实验设计

九连环玩具网上很容易买到。约定计步法：每把一个环套上或取下杆算一步（有的玩法把前两个环同时动算一步，结果会不同，以本集约定为准）。

组 做法 检验什么
A1 / 2 / 3 个环步数
B4 / 5 个环，推算 9 个递推
C记录 3 个环的状态格雷码
D纸卡模拟规则

操作步骤

  1. A：只用最前面的 1、2、3 个环（后面的先全部解下或忽略），各解一次，记步数。
  2. B：继续 4、5 个环，填表，用「新步数 = 上一个 + 2 × 上上个 + 1」推算到 9 个环。
  3. C：3 个环时每一步写下状态（1 在杆上、0 不在），检查相邻两行是否只差一位。
  4. D：用 3 张纸卡和一根筷子按规则模拟。
