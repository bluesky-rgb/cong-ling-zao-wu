# 视频渲染源码

纯 Python + Pillow 逐帧绘制（2 倍超采样抗锯齿），通过管道交给 ffmpeg 编码为 H.264。

| 文件 | 输出 |
| --- | --- |
| `lib.py` | 画布、配色、字体、缓动函数、渲染管道 |
| `shot10.py` | 镜头 10 · 磁感线计数（按偶极子磁场计算穿过线圈的磁感线） |
| `shot14.py` | 镜头 14 · 导线里的电子（洛伦兹力） |
| `shot17.py` | 镜头 17 · 交流电波形（电压 ∝ ω·sinθ 积分） |
| `shot18.py` | 镜头 18 · 法拉第铁环（接通、断开瞬间的感应电流） |
| `cards.py` | 第 04 集字幕卡、公式卡 |
| `titles.py` | 可复用的科技树片头片尾模板 |
| `roughcut.py` | 第 04 集粗剪样片（含占位画面） |
| `b1.py` | B1 指南鱼：原文卡、热剩磁、两种解释、片头片尾 |
| `roughcut_b1.py` | B1 粗剪样片 |

输出目录在各脚本中写为 `/home/claude/video/out`，使用前请改成自己的路径。
