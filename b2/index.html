卓筒井

没有钢铁钻机，北宋盐工靠冲击凿井、竹筒护壁、皮阀汲卤，把井打到几十丈深。

暂定标题没有钢铁钻机，怎么打出很深的盐井？
时长约 3 分 34 秒 · 13 个镜头
时代北宋庆历年间（1041–1048）· 四川
衔接← B14（盐卤）；→ 第三卷 制盐

背景

卓筒井

北宋庆历年间出现于四川，今大英县一带仍存古盐井。口小（约碗口大）、井深，取代了此前的大口浅井。

苏轼《蜀盐说》

「自庆历、皇祐以来，蜀始创筒井，用圜刃凿山……深者至数十丈」，并记载了用去节大竹作井壁、竹筒底部悬熟皮汲卤。引文以原书为准，拍摄前请再核对一遍原文。

燊海井

1835 年凿成于自贡，深约 1001 米，被称为世界上第一口超千米深井，用的是同一类冲击式顿钻法。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1打井要用坚硬的钻头往下钻 → 重锤反复下落，冲击破岩
  2. 2打通就能取卤 → 要用竹筒作井壁，挡住淡水和坍塌
  3. 3卤水提不上来 → 筒底装单向阀，靠水压开合

三层「为什么」

现象层

古人：铁锥冲击、竹筒作井壁、底部带皮阀的竹筒汲卤

规律层

经验：口小井深，隔绝淡水，卤水才浓

本质层

冲击把能量集中在钻头尖上破岩；单向阀靠两侧的水压差开合

原理 → 设计决策：岩石硬、人力有限 → 用杠杆把人的体重变成反复冲击；井壁会塌、淡水会渗 → 竹筒套管；井太深没法下去舀 → 带单向阀的长竹筒。

实验设计

三个小实验分别对应凿井、护壁、汲卤，道具都很便宜。

组 做法 检验什么
A螺丝刀绑重物，反复提起砸石膏块 50 下冲击能打多深
B同样时间用手拧螺丝刀对照：旋转
C湿沙桶里插管打孔，有 / 无吸管套管套管防坍塌
D塑料管底贴橡皮阀，提水单向阀能否把水提上来
E同一根管去掉阀片对照

操作步骤

  1. 石膏块：熟石膏加水倒进纸杯，凝固一天后脱模；或者用一块红砖代替。
  2. 重物可以用装沙的塑料瓶绑在螺丝刀柄上，每次提起约 20 厘米再放下，戴护目镜。
  3. 湿沙桶：透明塑料桶里装湿沙，中间一层加点水，用一根细管往下插再拔出，看孔会不会塌。
  4. 汲卤筒：直径 2–3 厘米的塑料管，底部用胶带只固定橡皮片的一边，让它能单向翻开；或在管口放一个乒乓球，下面用铁丝挡住。
  5. 每次提水后倒进量杯，记录毫升数。

实践时要验证

  • 冲击和手拧的深度差别是否明显
  • 湿沙模型能否清楚地拍出坍塌
  • 橡皮阀能否不漏水地提起一整管

安全与道具

安全提示
  • 冲击实验戴护目镜，石膏碎屑会飞溅；手不要放在落点附近。
  • 熟石膏粉不要吸入，搅拌时戴口罩。
