从零造物 · 古法解密 · B7

榫卯

榫插进卯，靠形状互锁和木材之间的挤压摩擦连接，不用钉子；接头能微微滑动，晃动时把能量消耗掉，所以更耐震。

暂定标题不用一根钉子，木头为什么能咬得这么紧？
时长约 3 分 36 秒 · 13 个镜头
时代约七千年前 · 河姆渡
衔接← B17 指南车；→ 42 马轭

背景

河姆渡

浙江余姚河姆渡遗址（约七千年前）出土了带榫卯的木构件。

应县木塔

山西应县佛宫寺释迦塔，辽清宁二年（1056 年）建成，高约 67.3 米，全木结构，不用铁钉和铁件；地方记载建成后至 1103 年间经历七次地震。

原理

榫卯靠形状限制移动方向，再靠重量压紧产生摩擦；半刚性的接头在晃动时会产生微小滑移和摩擦，消耗能量（耗能减震）。

理解路径

先说出观众最常见的误解，再用实验当场打破它。

  1. 1不用钉子就不牢 → 形状互锁同样很牢
  2. 2越死越结实 → 会微微动的接头更耐晃
  3. 3榫卯只是手艺 → 背后是受力方向和摩擦

三层「为什么」

现象层

鲁班锁拼起来就散不开；榫卯框架晃得更快停下

规律层

形状限制位移，压力产生摩擦

本质层

半刚性节点的滞回耗能

原理 → 设计决策：木头不好钉、钉子会锈 → 用形状咬合；地震会晃 → 让接头能微微滑动、耗掉能量；松了 → 敲一敲还能装回去。

实验设计

网购的榫卯积木或鲁班锁即可；对照用雪糕棍和热熔胶。

组 做法 检验什么
A直角接头：压、推、拔受力方向
B榫卯小方凳框架承重
C托盘摇晃对比耐晃
D加大幅度到损坏可修复

操作步骤

  1. A：把榫卯积木的一个直角接头拍特写，分别向下压、侧推、往外拔。
  2. B：拼一个小方凳框架，压一本书。
  3. C：用雪糕棍和热熔胶做一个同样大小的框架；两个框架并排粘在托盘上，来回推托盘 3 次后停下，慢镜头拍谁先停。
  4. D：逐渐加大推的幅度，记录哪个先坏、能否修复。
